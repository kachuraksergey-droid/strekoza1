# STREKOZA — сайт центру здоров’я

Статичний сайт на **Vite**: HTML, CSS і JS, анімації на GSAP. Зібраний за макетами з полотна «STREKOZA — редизайн».

## Сторінки

| Файл | Сторінка |
|---|---|
| `index.html` | Головна |
| `nigtovyi-servis.html` | Напрямок «Нігтьовий сервіс» |
| `vivace.html` | Апарат Vivace |
| `komanda.html` | Команда (з фільтром) |
| `404.html` | Сторінка помилки. Сюди ж ведуть посилання на сторінки, яких ще немає |

## Запуск

Потрібен Node.js 18+.

```bash
npm install
npm run dev       # локальний сервер з миттєвим оновленням → http://localhost:5173
npm run build     # збірка в папку dist/
npm run preview   # перегляд зібраного сайту → http://localhost:4173
```

Папку `dist/` після `npm run build` заливаєш на хостинг (Netlify, Vercel або звичайний хостинг через FTP). `dist/index.html` не відкривається подвійним кліком, його треба відкривати через сервер (`npm run preview`).

## Де що міняти

- **Ціни, майстри, напрямки, відгуки, бренди, телефон, адреса** — `vite.config.js` (об’єкт `site` на початку файлу). Сторінки беруть дані звідси при збірці.
- **Шапка, футер, блок «Запис», прайс** — `src/partials/*.hbs`. Змінюєш один раз, і зміна з'являється на всіх сторінках.
- **Стилі** — `src/styles/main.css` (кольори, сітка, типографіка, компоненти) і `src/styles/pages.css` (блоки сторінок).
- **Інтерактив** — `src/js/main.js`: мобільне меню, акордеон напрямків, відгуки, фільтр команди, анімації появи.
- **Фото** — `public/img/`, у двох розмірах: `назва-800.webp` і `назва-1600.webp`.

## Сітка й правила

- Десктоп: 7 колонок, поля 32, проміжок 24, максимальна ширина 1440.
- Мобайл (до 767px): 4 колонки, поля 16, проміжок 10.
- Шрифти 64 / 28 / 22 / 16 / 12, mono 10. Кольори в `:root` у `main.css`.
- Розміщення в сітці пишеться прямо в розмітці: `style="--c:4;--s:2"` — з 4-ї колонки на 2 колонки, на мобайлі `--mc` / `--ms`.
